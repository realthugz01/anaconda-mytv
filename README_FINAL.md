## Snelste APK Build (zonder Android Studio):

### Optie 1: GitHub Actions (Aanrader - 3 min)
1. Ga naar https://github.com/realthugz01/anaconda-mytv
2. Upload deze hele folder inhoud (overschrijf)
3. Wacht op Actions -> Download APK uit Releases

### Optie 2: PWA Install (Direct, geen build nodig)
1. Open op TV Box browser: https://realthugz01.github.io/anaconda-mytv/
2. Menu -> Install / Toevoegen aan beginscherm
3. Staat direct als app tussen je apps

### Optie 3: Capacitor Local
```
npm install
npx cap add android
npx cap open android
# Build APK in Android Studio
```

## Installeren op TV Box:
- Downloader app -> https://github.com/realthugz01/anaconda-mytv/releases/latest/download/app-debug.apk
- Unknown Sources AAN
